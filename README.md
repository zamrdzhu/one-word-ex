One word my ex would use to describe me: Clingy. Not angry, not cruel — just the honest verdict, delivered in a single word, that still stings because it is probably fair.

## The word

> Clingy

## Run it

```sh
python3 main.py
```

The program prints exactly one word and writes the same word (no trailing newline) to `/output/entry.txt`.

## Why this word

It is the funniest kind of honesty: the word that ends the argument because there is nothing left to argue with. "Clingy" lands as both a joke and a confession — the laugh comes with a wince, which is exactly the sting of recognition the brief asks for. It needs no context, no setup, and no defence, which is why it still hurts, and why it is the first word they would reach for.
